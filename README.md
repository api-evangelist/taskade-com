Taskade is an AI‑powered operating system that lets teams build apps, agents, and automated workflows in a collaborative workspace. It offers AI agents, customizable automations, project templates, and integrations with over 100 apps, targeting remote work, knowledge management, and productivity. The platform provides a low‑code environment for creating AI‑driven applications without extensive coding, supporting both individual and enterprise users.

**Areas:** Collaboration · AI · Productivity · RemoteWork · LowCode

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Taskade: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
